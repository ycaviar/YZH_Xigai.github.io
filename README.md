# 习概题库刷题系统

基于《习近平新时代中国特色社会主义思想概论》题库的在线刷题系统。

## 功能特性

- **答题模式**：即时模式（答完立即显示结果）与考试模式（统一交卷判分）
- **题号矩阵**：可视化跳转面板，显示答题状态（已答/未答/对/错）
- **错题本**：自动记录错题，支持按套题/题型筛选，答对一次即移出
- **闪卡背诵**：正面题干+选项，翻转显示答案，支持筛选与随机
- **题目搜索**：全文搜索题干与选项，快速定位
- **进度统计**：记录每套题进度、历史答题、正确率分析
- **个人笔记**：每题可添加笔记，跨套题共享
- **收藏与难度**：标记收藏题目，自评难度星级
- **深色模式**：自动跟随系统或手动切换

## 题库数据

- 原始题库：45 套题，共 3260 题
- 去重后：**670 题唯一题**（去重率 79.4%）
- 题型分布：判断题 182 / 单选题 214 / 多选题 274
- 包含「全部题库」套题，涵盖所有 670 题

## 部署说明

本项目为纯前端静态网页，无需后端服务。

### GitHub Pages 部署

1. Fork 或 clone 本仓库
2. 在 GitHub 仓库设置中，选择 **Pages** → **Source** → `docs` 分支
3. 访问 `https://你的用户名.github.io/仓库名/`

### 本地运行

直接用浏览器打开 `docs/index.html`，或启动本地服务器：

```bash
# Python
python -m http.server 8000 -d docs

# Node.js
npx serve docs
```

然后访问 `http://localhost:8000`

## 文件结构

```
docs/
  index.html      # 主网页（单文件应用）
  questions.js    # 题库数据
```

## 数据存储

所有用户数据（进度、错题本、笔记等）存储在浏览器 **localStorage** 中：
- 存储键：`xigai-quiz-data-v2`
- 数据不随题库更新自动迁移，题库大版本更新时可能需要清除旧数据

## 技术栈

- 纯 HTML/CSS/JavaScript（无框架）
- CSS 变量主题系统
- 响应式布局（移动端友好）
- localStorage 本地持久化

## 题库来源

原始题库来自《习近平新时代中国特色社会主义思想概论》课程配套资料，经 Python 脚本解析 docx 文件并去重合并。
